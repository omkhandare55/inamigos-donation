# Project Report: InAmigos Foundation Digital UI Overhaul

**Date:** May 15, 2026  
**Project:** InAmigos Foundation Official Donation Website  
**Focus Area:** UI/UX Engineering & Frontend Development  

---

## 1. Executive Summary
The objective of this project was to completely revamp the digital donation interface for the **InAmigos Foundation**. The original website utilized a direct link to Razorpay without a dedicated, trustworthy landing page. This project successfully delivered a premium, modern, and highly professional single-page application (SPA) that acts as an integrated Donation Hub.

## 2. UI/UX Strategy & Design Decisions

### A. Color Psychology
- **Primary Color (Vibrant Orange):** Used exclusively for Calls to Action (CTAs) like the "Donate Now" button to drive user conversion and excitement.
- **Secondary Color (Navy Blue):** Used for typography and backgrounds to instill a deep sense of trust, security, and institutional credibility.

### B. Visual Asset Enhancement
- **Removal of Emojis:** Standard emojis were removed from the platform to maintain a corporate and highly professional standard.
- **Integration of SVGs:** Custom, scalable vector graphics (SVGs) were implemented for the foundation's core initiatives (Education, Women Empowerment, Animal Welfare, and Environment).

### C. Layout Architecture (The Rubric)
The architecture rigorously follows the required structural rubric:
1. **Homepage / Hero:** Split-layout displaying immediate impact alongside the financial contribution form.
2. **About Us:** Details the founder's mission and vital NGO certifications (80G/12A).
3. **Services:** A clean grid layout explaining Project Bachpanshala, Udaan, Jeev, and Prakriti.
4. **Contact Page:** Accessible communication form with headquarters information.
5. **Additional Sections:** A dedicated "Volunteer" pipeline integrating directly with Google Forms.

### InAmigos Foundation - Official Donation Website

**Overview:**
A premium, modern, and trustworthy landing page designed for the InAmigos Foundation. This project was developed as a comprehensive solution to streamline the donation process while beautifully showcasing the NGO's core initiatives and certifications.

**🌟 Features:**
- **Split-Layout Donation Hero:** A psychological layout placing the impact statement side-by-side with a secure donation amount selector.
- **Trust Indicators:** Prominently displayed 80G, 12A, NITI Aayog, and ISO 9001:2015 certifications to establish immediate donor trust.
- **Interactive Causes Grid:** Showcases the 4 core initiatives using clean, professional SVG vector graphics.
- **Razorpay Integration Simulation:** A fully styled form that calculates the donation amount and seamlessly prepares for Razorpay payment processing.
- **100% Responsive Design:** Flawless viewing experience on Desktop, Tablet, and Mobile devices.

**🛠️ Technology Stack:**
- **HTML5:** Semantic architecture for accessibility and SEO.
- **CSS3:** Custom properties (CSS Variables) for a cohesive NGO color theme.
- **Vanilla JavaScript:** Handles the interactive donation amount selection, smooth scrolling, and form submission state changes.

**🚀 How to Run Locally:**
1. Clone or download this repository.
2. Open the `index.html` file in any modern web browser.
3. No backend server or build process is required!
