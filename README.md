# InAmigos Foundation - Official Donation Website

![InAmigos Banner](https://img.shields.io/badge/Status-Completed-success?style=for-the-badge) ![Tech Stack](https://img.shields.io/badge/Tech-HTML%20%7C%20CSS%20%7C%20JS-blue?style=for-the-badge)

A premium, modern, and trustworthy landing page designed for the **InAmigos Foundation**. This project was developed as a comprehensive solution to streamline the donation process while beautifully showcasing the NGO's core initiatives and certifications.

## 🌟 Features

- **Split-Layout Donation Hero:** A psychological layout placing the impact statement side-by-side with a secure donation amount selector.
- **Trust Indicators:** Prominently displayed 80G, 12A, NITI Aayog, and ISO 9001:2015 certifications to establish immediate donor trust.
- **Interactive Causes Grid:** Showcases the 4 core initiatives (Project Bachpanshala, Udaan, Jeev, Prakriti) using clean, professional SVG vector graphics.
- **Razorpay Integration Simulation:** A fully styled form that calculates the donation amount and seamlessly prepares for Razorpay payment processing.
- **100% Responsive Design:** Flawless viewing experience on Desktop, Tablet, and Mobile devices.

## 🛠️ Technology Stack

- **HTML5:** Semantic architecture for accessibility and SEO.
- **CSS3:** Custom properties (CSS Variables) for a cohesive NGO color theme (Trustworthy Navy Blue & Vibrant Action Orange), with glassmorphism and subtle hover animations.
- **Vanilla JavaScript:** Handles the interactive donation amount selection, smooth scrolling, and form submission state changes.

## 🚀 How to Run Locally

1. Clone or download this repository to your local machine.
2. Open the folder in your favorite code editor (e.g., VS Code).
3. Open the `index.html` file in any modern web browser (Chrome, Edge, Firefox).
4. No backend server or build process is required!
